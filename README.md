# WithUrDoctor Backend

WithUrDoctor Backend is a Node.js and Express API for a doctor consultation platform.

## Features

- Doctor Signup
- Email Verification
- Doctor Login with JWT
- Protected dashboard
- Doctor profile data
- Profile photo upload
- Gallery image upload
- MongoDB database

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Multer
- Nodemailer
